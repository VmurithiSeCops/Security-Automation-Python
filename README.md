# Security Automation & Python Utilities

## Overview
This repository showcases custom Python scripts designed for security automation, network utility tasks, and log file analysis. It demonstrates practical applications of Python in IT operations and security monitoring, aiming to reduce manual overhead during triage and reconnaissance.

---

## Technical Stack

* **Core Modules:** `socket`, `sys`, `os`, `datetime`
* **Focus Areas:** Task Automation, Socket Programming, Log Parsing & Filtering
